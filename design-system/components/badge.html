Badge

A small label that shows a status or a count. It never responds to a click.

Has gaps4 styles4 content typesDefault, Data, IconLight and darkFigma 7477:297479 ↗

LearnWhen to reach for it, and a live one to try.

When to use

One test: does it do anything when clicked? If not, it is a badge.

Use it for

  • A count on an icon or a tab, such as unread alerts.
  • The state of a unit, an update or a job, in a table or after a title.
  • A short flag on a row, such as Ignition on.

Use something else when

  • It filters, opens, selects or dismisses when clicked. Use a Chip.
  • The value is one of the nine truck phases. Use a Truck phase tag.
  • The message needs a sentence. Use a Notification.
  • It is not a status or a count. Use plain text.

UnderstandWhat it does by itself, and the choices you make.

Behaviour

What the badge does by itself. Nothing here needs a decision.

  • It does not respond to hover, focus or press. A badge that responds is a chip.
  • A number caps at 40px wide. Anything above 99 shows as 99+.
  • A word grows to fit. There is no width cap on text.
  • Only Error changes between themes. The light red reads 2.23:1 on a dark page, so dark uses a pale red with dark text.
  • The dot has a 1px ring inside its edge. The ring keeps it visible on any page. The footprint stays 8px.
  • Data is the same badge with 2px corners. Icon holds one 12px icon and no label. Both share the four styles.

Guidelines

The choices you make, and why.

  • Pick the style by emphasis. The word carries the meaning. See the table below. Styles are levels of emphasis, not meanings.
  • Write the number when you have one. A dot says something happened. A number says how much.
  • Use the Data type in tables and KPI rows. A column of pills reads as a row of buttons.
  • Place it by what it belongs to. Icon, line of text, table cell or tab. See the table below.
  • Let the label or column header name the status. Then the badge only has to say the value.
  • Keep one badge per object. Two badges on one row is a layout problem, not a status.
  • Need a colour the four styles do not have? Change only the fill, text and border. Check AA in both themes, then propose it to the library as a named style.

Do not

  • Make a badge clickable, hoverable or dismissible.
  • Use Error for numbers that are only high.
  • Rely on the dot’s colour alone to say which state it is.
  • Put a word on an icon. Use a number or a dot.
  • Use a colour that has not been checked in both themes.

Accessibility

  • A badge that changes on its own needs aria-live="polite" on its container.
  • A dot needs role="img" and a label, such as “Unread”.
  • Put the count in the accessible name: “Notifications, 12 unread”, not “12”.
  • Never let colour alone separate Error from Default. The word or number has to do it.
  • The dot is the information, so its edge needs 3:1 (WCAG 1.4.11). The ring provides it.

In the Angular code the Badge is one ready-made piece. Every colour, size and state on this page is already inside it, so the person building a screen chooses from the settings below and never restyles anything.

  • What you type<vf-badge>
  • What you can setkind (one of: number, text, dot), style (one of: default, alternate, outline, error), value (number or short word), label (accessible name for a dot)
  • What it tells youNone. It only displays.
  • What it handles for youA <span>; the dot form gets role="img" and aria-label. Numbers above 99 render as “99+”. A container whose badge changes wraps it in aria-live="polite".

Known gaps

  • The light dot ring is #9B958A in Figma. It reads 2.57:1 on the page, under the 3:1 a meaningful dot needs. Build with #171614 (neutral/950), as this page does. Fix: rebind badge/dot/stroke Light to neutral/950.
  • Figma calls the style property “state”. A badge has no states. Rename the property to Style so Figma, this page and the code agree.
  • Two token names do not match their style. The Default chip is filled by badge/dot/fill/default, not badge/display/brand/background. The Alternate dot uses badge/dot/fill/Information. Rebind or rename so each name matches its style.
Recommended: a darker Outline border#41A8F2 reads 2.24:1 on the page. primary/600 (#0975C3) would read 4.17:1. Not a failure: the word identifies the badge, so WCAG 1.4.11 does not require the edge.
