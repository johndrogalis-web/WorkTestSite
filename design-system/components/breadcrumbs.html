Breadcrumbs.

Breadcrumbs show where a page sits in a hierarchy and let someone climb back up it. They are navigation, never filters, and never a substitute for a page title.

Has gapsBuilt in FigmaMolecule (trail) + atom (items)Figma 63904:41676 ↗
Built in Figma now. Two sets: BreadcrumbItem (link, current page and overflow, each with default, hover, active and focus) and Breadcrumb Group (three, four and five levels at desktop, tablet and mobile). The values on this page are the Figma tokens, with two exceptions called out under Accessibility where the token fails contrast and the page carries the passing value instead.

Anatomy

  • TrailA navigation landmark named “Breadcrumbs” wrapping an ordered list. That name is what a screen reader announces.
  • Link itemA standard crumb with the full interactive state set. #0975C3, ABC Repro 14px / weight 400.
  • Current pageThe last item. Static text, aria-current="page", not focusable, no states. #666054.
  • Overflow triggerA … button that opens a menu of the collapsed items.
  • SeparatorA 12×12 angle-right, aria-hidden, generated in CSS. Never focusable, never announced.
  • Item padding6px, radius 4px
  • Gap between items8px
  • Container height16px — reserved even when no trail renders, so the page below it does not jump
Placement is part of the spec. Breadcrumbs sit in the content area above the page header. They are not embedded inside the header component, and the container keeps its height on pages with no trail so headings never shift.

In Angular

For developers. Nothing in this section changes how the Breadcrumbs. looks or behaves. If you design in Figma or write the rules, you can skip it.

In the Angular code the Breadcrumbs. is one ready-made piece. Every colour, size and state on this page is already inside it, so the person building a screen chooses from the settings below and never restyles anything.

  • What you type<vf-breadcrumbs>
  • What you can setitems (array of { label, href }, last item is the current page), maxVisible (defaults from breakpoint)
  • What it tells younavigate (item) when an item is a router link rather than a plain href
  • What it handles for you<nav aria-label="Breadcrumbs"> around an <ol>; the last item is aria-current="page"; the overflow is a <button aria-haspopup="menu"> that opens the menu container.

Behaviour

What gets dropped first

As the container narrows, three things happen in this order. Knowing the order is what stops people inventing a fourth.

  • 1 · Per-item truncation. Labels over 30 characters get an ellipsis and a tooltip. Nothing has been removed yet.
  • 2 · The current page name drops. It is already the page title below, so removing it costs no context.
  • 3 · Middle items collapse into the overflow menu. The first item always stays visible. Collapsed items appear in hierarchical order.
Breadcrumbs never wrap to a second line. Not at any width, not for any depth. If it does not fit, it truncates or collapses.

Guidelines

Do

  • Use breadcrumbs to communicate a genuine hierarchical relationship.
  • Keep the trail consistent — the same page reached two ways shows the same trail.
  • Let the first item stay visible at every width. It is the anchor.
  • Put them above the page header, in the content area.

Do not

  • Do not use breadcrumbs as filters. A filter state is not a hierarchy.
  • Do not use them for lateral navigation between peers — that is tabs.
  • Do not indent the items inside the overflow menu. It reads as a second hierarchy and makes the menu harder to scan.
  • Do not repeat the current page as both a crumb and the page title on mobile.

Specs

  • FontABC Repro 14px / 18px line-height / weight 400
  • Link colour#0975C3 light, #41A8F2 dark. Tokens breadcrumb-item/text-default.
  • HoverText #0D598F / #1594EF, fill #DFDEDD / #000000
  • Focus ring2px, #171614 / #D0CEC8
  • Current page colour#666054 light, #B6B1A5 dark (the Figma token is #7F796C, which fails; see Accessibility)
  • Separator colour#666054 light, #7F796C dark. Unicons angle-right.
  • Overflow“. . .” with a 12px caret, opening a menu of the collapsed items (Menu Container, 16px radius, 6px padding, 30px items)
  • Separator size12 × 12

  • Item radius4px

  • Container height16px, reserved
  • Truncation30 characters, tooltip caps at 80
  • Touch target24 × 24 minimum
  • MotionHover 200ms · tooltip in 200ms ease-out · menu open 200ms ease-out, close 200ms ease-in

Accessibility

Structure

  • <nav aria-label="Breadcrumbs"> wraps the whole thing, giving it a landmark.
  • An ordered list inside — ol > li — because the sequence is the meaning.
  • aria-current="page" on the last item, which is not a link.
  • Separators carry aria-hidden="true" and are never focusable.

Keyboard

One pair still fails, and it is not a breadcrumb problem. The product link blue #0975C3 measures 4.17:1 on the light base surface, where most pages put their breadcrumbs. It passes on white. This is the same link-blue question tracked on Open items and it needs a decision about the link colour itself, not a change here.
Two Figma tokens are overridden on this page. The active and focus text token lightens the link to #1594EF, which is 3.22:1 on white; the page keeps the default link colour in those states instead. The dark current-page token is #7F796C, 3.80:1 on the dark surface; the page uses #B6B1A5. Both are listed under Known gaps for Figma.

Screen reader

  • “Breadcrumbs, navigation” on entering the landmark.
  • Each item announced as a link with its label.
  • The last item announced with “current page”.
  • The overflow trigger announced as a button.
  • Separators are not announced at all.

Known gaps

Built, specified, and one colour short of Solid. The component exists in Figma with every state and breakpoint, and every value on this page is decided. The one thing left is the product link blue, which fails on the light base surface, and that is a decision about links everywhere, not about breadcrumbs.

Still open

  • Link colour on the light base. #0975C3 is 4.17:1 on #F0EEEA. Tracked on Open items as the link-blue question; whatever is decided there applies here.

Figma housekeeping

Things the design file still has to catch up on. None of them change what is specified here.

  • Retire breadcrumb-item/text-active and text-focus, or point them at text-default. The lighter blue fails 4.5:1 and the state is already carried by the fill and the ring.
  • Rebind breadcrumb-item/text-current-page in dark mode from neutral/400 to neutral/200 (#B6B1A5).
  • The old six-level Breadcrumbs set (2703:7) is still on the page. Breadcrumb Group is canonical; retire the old one.
  • The overflow caret is a Feather glyph and the separator is Unicons. Pick one library for both, per the icon rule.
