Button

The action component. Five variants for five levels of emphasis, four sizes, icons before or after, and the hover, focus, pressed, disabled and loading states that the rest of the system reuses.

Has gaps6 variants4 sizesLight and darkFigma 65791:5246 ↗
What it is. The one component every screen uses. Six variants that say how important an action is, four sizes, optional icons, and one set of states that every other clickable thing in Trinity borrows: the Segmented control is literally a row of these. Primary is blue in light mode and the brand yellow in dark; the rest keep their role in both.

Try it

These are real buttons. Hover for the lighter fill and the thin outer stroke, tab to one for the double focus ring, hold the pointer down for the pressed colour. Click the last two to see the loading state: the label hides, a spinner takes its place, and the width does not change.

Anatomy

  • ContainerA pill: 100px radius, fill from the variant, horizontal auto layout, 8px gap between icon and label
  • LabelABC Repro Medium 14px, line height 130%, in every size. The label frame carries 8px of its own side padding, so text sits 24px from the edge
  • Prefix and suffix iconOptional, 16px TrinityIcons glyphs in the label colour. Either, both or neither
  • BorderSecondary and Destructive secondary have a 2px inside border, Ghost and Destructive a 1px one. Primary and Accent have none
  • SpinnerLoading replaces the content with a 24px arc in the spinner colour. The button keeps its width

Behaviour

  • One Primary per view. If two actions both feel primary, one of them is Secondary. If nothing completes the task, there is no Primary on that screen.
  • Labels are verbs: Add a truck, Export, Delete ticket. Never OK, Yes or Submit on its own.
  • A button does something; a link goes somewhere. If the result is navigation, use a link styled as text, not a Ghost button.
  • Destructive never fires on the first click when the loss cannot be undone. Open a Modal and put the Destructive button there, next to a Ghost Cancel. Destructive secondary follows the same rule when the step cannot be undone; when it can (remove a line you can add back), it may act at once.
  • Loading replaces the click, not the button: the button stays where it is, at the same width, so the user can see which action is in flight.
  • Buttons size to their label. Only stretch to full width on mobile action bars and modal footers, and then stretch every button in the row.
  • Order in a row: Primary on the right, Secondary or Ghost to its left, Destructive on the far left with space between.

Guidelines

Do

  • Use Primary once per screen, for the action the screen exists for.
  • Use Ghost for the quiet actions around a table or card.
  • Use Large on desktop, XLarge on mobile so the target is at least 44px.
  • Pair an icon with a label unless the icon is universal (close, add, search).
  • Disable a button only when the reason is visible on screen.

Do not

  • Do not put two Primary buttons next to each other.
  • Do not use Destructive for cancel or close; those are Ghost.
  • Do not use Destructive secondary to soften a delete that cannot be undone. Quieter is not safer.
  • Do not change a label while the button is loading.
  • Do not use Accent as a second Primary. It is a highlight, not a call to action.
  • Do not restyle a button locally. If a state is wrong, fix the token.

Accessibility

Every default label passes AA. Three transient states do not: the Primary hover label in light, and the pressed labels of Secondary and Ghost in dark. Hover and pressed last a fraction of a second, but WCAG does not exempt them, and the fix is a token change, not a page decision.

Disabled is exempt. WCAG 1.4.3 excludes inactive controls, so the 2.75:1 disabled label is not a failure. The light Accent fill is 1.32:1 against the page, which is also fine: the label carries the contrast, and a button boundary is not required.
  • It is a <button>. Never a div with a click handler; never an <a> unless it navigates.
  • The label is the accessible name. Icon-only buttons get aria-label; a tooltip is not enough.
  • Focus is visible on keyboard only, with the double ring, and the ring passes 3:1 in both themes.
  • Loading sets aria-busy="true"; do not also set disabled, or the focus is lost.
  • Large is 40px, below the 44px touch guidance. Use XLarge on mobile.

Known gaps

Specified here; three token fixes in Figma. The page is the spec. The colours below are read from the Figma variables, so the fix lands here the moment the tokens change.
  • Primary hover label, light. White on #41A8F2 is 2.59:1. Either darken button/primary/hover to at least #2A8ED6 range (4.5:1 with white) or hover from #0975C3 down to #0D598F and use a lighter tone for pressed.
  • Secondary and Ghost pressed, dark. #7D811E (yellow at 40%) and #9B958A put their labels at 4.17:1 and 4.04:1. Raise the label to white on Ghost pressed, or darken the pressed fills a step.
  • Small and Medium are both 32px. Small has no icon slots and 4px vertical padding, so it renders the same height as Medium. Decide what Small is for (a 24px inline size, or drop it).

Figma housekeeping

  • The Ghost focus variant binds its inner ring to button/accent/focus-inner-stroke, not button/ghost/focus-inner-stroke. The page uses the ghost token.
  • The set has no description. The first paragraph of this page will do.
  • The updated set with Destructive secondary lives in the playground (65791:5246) and still needs to go back to the master file.
  • Dark hover and pressed for Primary, Secondary and Accent are opacity blends of the yellow. Consider flattening them to hex tokens so code and Figma agree to the digit.
