Verifi Design System/Components/Card

Card

Two organism shells built on slots. Card holds a truck, a ticket or an order and can be selected; Status Card holds a device and wears its health as a strip along the bottom.

Has gapsCard 3 types · 2 viewsStatus Card 5 statuses6 headersLight onlyFigma 63493:8711 ↗Status Card 63716:15725 ↗Guide 65926:18926 ↗
What changed in this version (October 2026). Read against the Cards page as it stands today, which John has said is close but still moving. New since the last page: the Card set is now 20 variants on three axes (Type × View × State) with a Compact view at 10px; the Input Card Header is a swappable sub-component with six variants; four content molecules are pre-built; Status Card is its own 20-variant set with five statuses; and the file carries a walkthrough with recipes and a Do / Do not list. Default shadow is now 0 0 3px, hover is the cyan glow, and the focus ring is a token. Still light only.
What it is. The unit of the dispatch board and the device list. A Card is a shell with a slot; what makes it a truck card or a device card is the header you swap in and the molecule you drop in the slot. The shell owns the states; the strip owns the status.

Anatomy

Two Level 3 organism shells built on native Figma Slots: Card and Status Card. Both are assembled from three modular pieces and nothing is ever detached.

  • Shell#FEFFFF surface, 1px #DAD8D7 border, 8px radius, a 0 0 3px shadow at 12%. Padding 20px (View = Default) or 10px (View = Compact)
  • Input Card HeaderOptional, Type = Input only. Six variants swapped in from the right sidebar: Radio, Checkbox, Ticket Status, Ticket Check, Detail, Device. 22px tall; the radio or checkbox sits on the right
  • Content slotAny content. Four pre-built molecules in the file: detailed-truck-content (110px), compact-truck-content (50px), device-detail-content (84px), truck-status-content (62px). Gap to the header 10px
  • Status stripStatus Card only. A full-bleed 31px band across the bottom, coloured by Status, with one line of diagnostic text that can be overridden
  • StatesHover: #00A1E0 border and a 0 4px 12px cyan glow. Selected: 2px #0C79A8 border on a #EEF9FF tint. Focus: a 2px #0C79A8 ring with 4px blur
The golden rule. In Figma, set the Selectable Content wrapper, the header and the content slot to Hug after dropping content. They default to Fixed, and a fixed Input card clips everything at 82px.

Behaviour

These are rules, not suggestions. Figma defines the shells, headers, content molecules and strips; the interaction rules are house convention and binding for new work.
  • The whole card is the target. On an Input card, clicking anywhere toggles the radio or checkbox in the header. The control is the indicator; it is not the only hit area.
  • Radio header means one; Checkbox header means many. Cards in one list share one header type. Never mix.
  • A Navigational card is a link. Render it as one. No header, no selection, and the whole card goes somewhere.
  • A Static card is not interactive and shows no hover. If it needs an action, put a Button inside it.
  • Status drives the strip and nothing else. Switch the Status variant; never recolour the strip, and never let the strip colour the whole card.
  • Alarm carries a dot as well as a colour, so it reads without colour vision. Keep it.
  • Compact below 600px and in dense lists. Same content, 10px padding, the compact content molecule.
  • Content hugs. Cards grow to their content; they are never a fixed height in a list, because the one with the longest line decides the row.

Guidelines

Do

  • Use Card for selectable truck, ticket and order items.
  • Use Status Card wherever a bottom hardware-health strip is needed.
  • Swap headers with the Card Header instance swap, never by detaching.
  • Set Selectable Content, header and content to Hug after dropping a molecule.
  • Use the pre-built content molecules before drawing a new one.

Do not

  • Do not detach a Card or Status Card to add rows — drop a molecule or a custom auto layout into the slot.
  • Do not recolour the status strip by hand — switch the Status variant.
  • Do not leave an Input card on a fixed 42px inner height when the content has more than one line.
  • Do not put a Button inside a Navigational card. A link inside a link is a trap.
  • Do not use a card for a single line of text. That is a list row.

Accessibility

Every strip clears AA with room: Normal 11.3:1, Warning 9.2:1, Alarm 10.6:1, Not installed 7.5:1. Ink on the selected tint is 16.9:1. The selected border (4.55:1) and the focus ring (4.86:1) both clear the 3:1 for a boundary. The hover border does not: #00A1E0 on the card is 2.92:1, just under 3:1. Hover is a hint and the shadow helps, so this page keeps it, but it is listed under Known gaps.

  • An Input card is an <article tabindex="0"> with aria-selected; a set of them is a role="radiogroup" or a group of checkboxes, with arrow-key movement and Space to select.
  • A Navigational card is an <a>. Its accessible name is the title, not the whole contents.
  • Selection is shown by the control and the border, not the tint alone. Alarm is shown by the dot and the text, not the red alone.
  • The status strip is role="status" so a change from Normal to Alarm is announced.
  • Focus is visible on the card itself, not only on the control inside it.
  • Minimum target: the whole card. Never shrink a Compact card below 44px tall.

Known gaps

  • Pending strip has no token. The guide shows a teal-blue strip; nothing in the variable set names it. This page uses #EEF9FF / #0C79A8 (primary/50 and the selected border) as a stand-in. Publish status/pending/100 and /900.
  • Hover border is 2.92:1. #00A1E0 on the card misses 1.4.11 by a hair. #0090C9 would clear it. Low stakes, since hover is transient and the shadow lifts the card, but it is the one failing value on the page.
  • No dark-mode tokens. The card is white on the dark page. If that is the intent, say so in the file; if not, a dark set is needed.
  • Default border is 1.42:1. Fine under the shadow, invisible without it. Decorative, so not a failure.
  • John is still revising the set. This page reflects the file as read on 19 October; expect the headers and molecules to move.
