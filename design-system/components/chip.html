Verifi Design System/Components/Chip

Chip

A pill you can press. It filters a list, shows what was picked, or runs one action, and it can be removed. Two sizes, light and dark, every pair passing.

Solid2 sizesLight and darkFigma 62644:15248 ↗
The badge test, the other way round. A chip does something when you click it: it filters, it selects, it can be removed. That is what separates it from a Badge and a Tag, which only display. If yours cannot be clicked, it is not a chip.

Anatomy

  • ShapePill, fully rounded, with a 1px outer ring of transparent padding so the focus ring has room
  • Large32px tall, 6px padding, 12px gap
  • Small24px tall, 4px 8px padding, 6px gap
  • LabelABC Repro Regular 14px, both sizes
  • IconOptional, 16px, before the label
  • Indicator dotOptional, 12px, before the label. Carries a colour that means something elsewhere on the page, such as a truck phase
  • DismissOptional 16px × after the label. Removes the chip
  • Border1px in the ink colour, both states

In Angular

For developers. Nothing in this section changes how the Chip looks or behaves. If you design in Figma or write the rules, you can skip it.

In the Angular code the Chip is one ready-made piece. Every colour, size and state on this page is already inside it, so the person building a screen chooses from the settings below and never restyles anything.

  • What you type<vf-chip>
  • What you can setlabel, selected, size (one of: lg, sm), removable, icon, dot (colour token name), disabled
  • What it tells youselectedChange (boolean), remove (void)
  • What it handles for youThe chip is a <button aria-pressed>; the × is a second <button aria-label="Remove {label}">. A row of chips is wrapped by the page in role="group" aria-label.

Behaviour

  • Three jobs, one shape. A filter chip toggles on and off and stays on screen. A selection chip shows something the user picked and is removed with the ×. An action chip runs one command and does not stay selected. Decide which one it is before you place it.
  • Click anywhere on the chip to toggle it. The × is a separate target that removes it; it never toggles.
  • Filter chips live in a row above the thing they filter, most-used first, and wrap to a second row rather than scrolling.
  • Removing the last selection chip leaves an empty row, not a placeholder chip. Say “No filters” in plain text if the emptiness needs explaining.
  • The indicator dot borrows a colour that already means something on the page — a truck phase, a severity. It never introduces a new one.
  • Labels are one to three words. “Plant: Rockdale” is the pattern for a chip that stands for a filter value.

Guidelines

Do

  • Use chips where the user chooses from a short set and wants to see what they chose.
  • Keep the selected state obvious: the inverted fill, never a tint.
  • Put the × only on chips that can be removed.
  • Use Small inside dense rows such as table filters; Large everywhere else.

Do not

  • Do not use a chip to display a status. That is a Badge.
  • Do not use one for navigation. That is a Tab or a link.
  • Do not mix filter chips and action chips in one row.
  • Do not put more than about twelve in a row without a “More” control.

Specs

  • Height32 large, 24 small
  • Padding6px large, 4px 8px small, plus a 1px transparent ring outside
  • Gap12px large, 6px small
  • Radius100px
  • Border1px, #211F1C light, #DFDEDD dark
  • Fill#DFDEDD / #171614; hover #B6B1A5 / #211F1C
  • Selected#171614 / #DFDEDD; hover #565147 / #B6B1A5
  • LabelABC Repro Regular 14px; #171614 / #FFFFFF; selected #FFFFFF / #211F1C
  • Focus1px outer ring + 2px inner ring (1px at Small)
  • Motion0.14s on fill

  • A filter chip is a <button aria-pressed>. A screen reader then says “Loaded, toggle button, pressed”.
  • The × is its own button with its own name: “Remove Loaded”, not “close”.
  • A row of chips is a group with a label: role="group" aria-label="Filters".
  • The indicator dot is decorative; the word carries the meaning. Never a dot with no label.
  • Disabled chips stay in the tab order with aria-disabled, so people can find out they exist.

Known gaps

Solid, as a starting point. Two sizes, every state valued, every pair passing, and the three jobs a chip can do written down. Nothing here blocks a build. Verifi is still discovering its full brand, so this can change — together, and always passing AA.

Two tidy-ups for Figma: add a disabled variant to match the chip/label-disabled token that already exists (the page rules 42% opacity, the same as Toggle), and give the small size its own focus ring token value, since small/inner-stroke-focus is 1px where large is 2px and the two should read the same.
