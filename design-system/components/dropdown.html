Dropdown

One choice from a closed set of five to fifteen options. If the user might need a value that is not in the list, this is the wrong component.

Has gapsFigma 51689:13501 ↗
The box is the text field. Padding, height, radius, border colours and every state come from Text field. Only the chevron and the open menu belong to this page.

Behaviour

Five to fifteen. Under five options, use a radio group — all of them fit on screen and nobody has to open anything. Over fifteen, add a filter inside the menu or use a search field with suggestions.
  • The menu opens below by default and flips above when there is no room.
  • It closes on outside click, on Escape, and on selection.
  • The currently selected item is marked in the menu, not just in the field.
  • Long option labels truncate in the field but never in the menu.

Guidelines

Do

  • Order the options the way the user thinks about them.
  • Use a placeholder that names the choice — “Choose a plant”.
  • Preselect when there is a sensible default.

Do not

  • Do not use a dropdown when the user may need a value that is not listed.
  • Do not use one for two options. That is a radio group or a toggle.
  • Do not nest a dropdown inside a dropdown.
  • Do not hide the selected value behind a generic label such as “Selected”.

Specs

  • FieldInherits every dimension from Text field
  • Chevron14 × 14
  • Menu radius16px
  • Menu padding6px
  • Item padding9px 11px
  • Item radius8px
  • Menu offset4px below the field
  • Max height320px
  • SizesLarge, small and jumbo exist as variants; only large has published values

Accessibility

  • A native <select> is the right answer more often than people think — it is keyboard and screen-reader correct for free, and on mobile it gets the platform picker.
  • If you build a custom one, it needs role="combobox", aria-expanded, aria-controls, and a listbox with aria-selected on the chosen item.
  • Arrow keys move through options, Enter selects, Escape closes and returns focus to the field.
  • Type-ahead should jump to the first matching option.
  • The label must stay visible when the menu is open.

Known gaps

  • No focus state on the public set. Interim rule: the field takes the same focus treatment as a text field — darkened border plus a 2px ring.
  • Three sizes, one set of values. Large, small and jumbo exist as variants but only large is specified.
  • No multi-select variant. If you need one, the closest published thing is the popover in multi-select mode.
  • Dark mode is not drawn.
