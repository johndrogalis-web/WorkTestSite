Image block

A frame with a fixed shape and a picture that fills it. Five aspect ratios, no states, no chrome.

Solid5 ratiosFigma 51681:83245 ↗
A frame with a picture in it, and nothing else. The Image block fixes the shape; the picture fills it. Five aspect ratios, no states, no chrome. Everything that happens around a picture — captions, overlays, links — belongs to the thing that contains it, not to this component.

Anatomy

  • FrameA box with a fixed aspect ratio. Width comes from the layout; height follows the ratio
  • PictureFills the frame, scaled to cover, cropped from the centre. Never stretched
  • RadiusSet by the container it sits in: 16px in a card, 8px in a list row, 0 when it bleeds to the edge
  • Ratios16:9, 5:3, 3:2, 4:3, 1:1

In Angular

For developers. Nothing in this section changes how the Image block looks or behaves. If you design in Figma or write the rules, you can skip it.

In the Angular code the Image block is one ready-made piece. Every colour, size and state on this page is already inside it, so the person building a screen chooses from the settings below and never restyles anything.

  • What you type<vf-image>
  • What you can setsrc, srcset, alt, ratio (one of: 16:9, 5:3, 3:2, 4:3, 1:1), width and height (real pixels), eager (boolean, default false)
  • What it tells youerror (void), so the parent can decide whether to drop the block
  • What it handles for youA <figure> with aspect-ratio and an <img loading="lazy"> unless eager. Keeps the placeholder fill on error. Never renders without an alt attribute, empty or not.

States

None. An image block is not interactive. When it sits inside a link or a card, that container carries hover and focus; the picture does not change.

ConditionWhat shows
LoadingThe placeholder fill, at the final size, so nothing moves when the picture arrives.
FailedThe placeholder fill stays, with the alt text visible inside it if the browser shows it. Never a broken-image icon.
No pictureDo not render the block. An empty frame is not a state.

Behaviour

  • The frame never changes shape for the picture. A portrait photo in a 16:9 block is cropped, not letterboxed. If the crop loses the subject, pick a different ratio or a different picture.
  • Reserve the space. Give the image its real width and height so the browser holds the box before the file loads. Layout shift is the most common image bug and it is entirely avoidable.
  • Serve at least two sizes and let the browser pick, so a 320px thumbnail does not download a 1600px file.
  • Load lazily below the fold, eagerly above it. A hero image should never be lazy.
  • Photographs follow the brand imagery rules: real people, real sites, natural light. Renders are for hardware. See Imagery.

Guidelines

Do

  • Choose the ratio from what the picture is for, not from the picture you happen to have.
  • Keep one ratio per row or grid.
  • Write alt text that says what the picture shows, or leave it empty when the picture is decoration next to text that already says it.

Do not

  • Do not stretch, skew or letterbox. It crops.
  • Do not put text on top of a picture without a scrim; the contrast is unmeasurable.
  • Do not use the block for icons or logos. Those are their own components.
  • Do not mix 3:2 and 16:9 in one grid; the rows will not line up.

Specs

  • Ratios16:9 · 5:3 · 3:2 · 4:3 · 1:1
  • FitCover, centred
  • RadiusInherited from the container: 16 / 8 / 0
  • Placeholder#DFDEDD light, #2F2D28 dark
  • LoadingLazy below the fold, eager above
  • SizesAt least two: one for the layout width, one at 2× for high-density screens

Accessibility

There is no colour to measure. The accessibility work on an image is the alt text and the layout.

  • Every picture has an alt. It describes what is shown when the picture carries information, and it is empty (alt="") when the text beside it already says the same thing.
  • Alt text does not start with “image of”. The screen reader already says that.
  • A picture that is a link takes its name from the link text or the alt, never from both.
  • Text over a picture needs a scrim behind it that measures 4.5:1 with the text at the picture’s lightest point, or the text goes beside the picture instead.
  • Reserved space is an accessibility feature: layout that jumps while loading throws off anyone using magnification.

Known gaps

Solid. Five ratios, one fit rule, a placeholder for loading and failure, and the alt-text rule. There is nothing in Figma to catch up on; the set has no states because it needs none.
