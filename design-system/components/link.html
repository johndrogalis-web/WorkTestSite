Link

The inline link: a word or phrase inside a sentence that takes the reader somewhere. It keeps the paragraph’s type and changes only colour and underline.

Anatomy

  • TextThe linked phrase. Font, size, weight and line height come from the paragraph it sits in
  • Colourlink/link at rest, a different token per state
  • UnderlineAlways on: 1px, 2px below the baseline; 2px on hover and press
  • Focus ring2px outline, 2px offset, radius 2, on keyboard focus only

Options

Linkinline · 1 type

One type. The Link has no sizes: it is the size of the text around it.

Link or Link button?

Link (.vf-link)Link button (.vf-btn.link)
DoesNavigation: another page, a section, an external siteAn action: opens, saves, filters, toggles
Element<a href="…"><button type="button">
SitsInside a sentenceOn its own, in toolbars, tables, cards and footers
LooksBlue, underlined, the paragraph’s typeNo border, pill hover fill, 14/500 label

Choose by purpose, not by look. If it does something, it is a button. If it goes somewhere, it is a link, even when it sits alone.

Behaviour

These are rules, not suggestions. The Figma Link atom (65835:47147) sets the states, scope and link-text rules. The rest is established UX practice. Build to this.
  • It navigates. A link goes somewhere and the URL can be copied, bookmarked and opened in a new tab. Anything that runs an action is a Button.
  • Same tab by default. Open a new tab only for an external site or a document that would lose the reader’s work, and say so.
  • It wraps. A long link breaks across lines like the rest of the sentence; the underline follows it.

Where to use it

ContextUse the Link?
Paragraph body copyYes, the main use
CaptionsYes
Helper text under a form fieldYes
List itemsOnly when the list is body content
Table cellsOnly when the cell holds prose, not a data value

Everywhere else a component already owns the link: headings and card titles (heading or card-link pattern), navigation, Breadcrumbs, Tabs, form labels, column headers, data values in a Table (row or cell navigation), Notification titles, empty-state headings and status Badges. Never put a link in a Tooltip: it cannot be reached.

Guidelines

Do

  • Use it inside a sentence or paragraph.
  • Keep the underline, so it is a link without relying on colour.
  • Link the phrase that names the destination.
  • Match the surrounding type and test keyboard focus.
  • Give the same destination the same link text everywhere.

Do not

  • Do not write “click here”, “read more” or a raw URL.
  • Do not remove the underline.
  • Do not use a link to run an action.
  • Do not put links next to each other without words or punctuation between them.
  • Do not use it for headings, labels or navigation; those components carry their own links.

Accessibility

  • Always underlined. Colour alone does not show it is a link (WCAG 1.4.1). In dark the link blue is close to the white body text (1.32:1), so the underline is what marks it.
  • A real <a href>. Never a span with a click handler, never an anchor that runs an action.
  • Visible focus on :focus-visible; the ring is the cue, not the colour change (2.4.7).
  • The purpose is clear from the link text or its sentence (2.4.4).
  • A link that opens a new tab says so in its accessible name.

Known gaps

  • Link blue on the light page surfaces. link/link #0975C3 is 4.17:1 on #F0EEEA and 4.41:1 on #F6F4F2, under 4.5:1; pressed and focus #0B7ACA are 3.90:1 and 4.12:1. All pass on white, so this page shows the Link on a white card. Until the token changes, put body copy with links on white. The hover colour #0D598F passes everywhere (6.38:1 on #F0EEEA) and would work as the default.
  • Link dark hover and pressed are not in Figma. The dark default #C5E4FB is read from the file (banner/link/default, Banner dark frame 38356:1239). Hover #EEF9FF, pressed #94C5FD and the #DFDEDD focus ring are derived from the blue ramp; all pass on the dark surfaces.
