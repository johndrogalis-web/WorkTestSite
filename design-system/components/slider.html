Verifi Design System/Components/Slider

Slider

A 4px track with a 24px ringed thumb, in single and range forms. The one component in this pass whose dark mode was fully specified.

Has gaps8 positionsSingle and rangeLight and darkFigma 53714:4469 ↗
The track has the same problem as the Progress bar, and worse in dark. #DFDEDD measures 1.16:1 on the light page and #393632 measures 1.37:1 on the dark one, so the unfilled part of the track is invisible in both themes. The two components also use different dark track colours, so they are not actually sharing a token.

  • FillSame height, drawn from the left edge to the thumb

  • Thumb ring6px at rest, plus a 1px outline on hover, 8px when active — heavier as you interact, while the 24px target never changes
  • Value bubble24px tall, 4px radius, active state only

Default, hover and active. The value bubble appears only while active.

The thumb grows on interaction; the target does not. Confirmed by Verifi Design: the visible ring gets heavier as you hover and then drag, so you can see where you are, while the 24px touch point stays exactly the same size throughout. Read hover-stroke: 1 as a 1px outline added to the 6px resting ring rather than a replacement for it.
There is no focus state and no disabled state. For a control that is dragged, focus matters more than hover, and it is the one that is missing.

Behaviour

  • The fill runs from the left edge to the thumb. On the range variant it runs between the two thumbs.
  • The value bubble appears above the thumb while the thumb is active, and shows the current number.
  • Nothing defines the step size, so whether this control moves in ones, fives or tenths is a per-implementation decision today.
  • Nothing defines what happens when the two range thumbs collide.

Guidelines

Do

  • Show the current value. The bubble only appears while dragging, so put the number somewhere permanent as well.
  • Use a slider when the rough size of the change matters more than the exact number.
  • Give the track enough width that a single step is a visible movement.

Do not

  • Do not use a slider when the exact value matters. Use a number field.
  • Do not use it for more than about twenty steps without also showing the number.
  • Do not ship it without a focus style. Keyboard users cannot see where they are.
  • Do not rely on the 24px thumb as the touch target on a phone.

Specs

  • Track height4px
  • Track radius4px
  • Thumb24 × 24, radius 9999
  • Ring, rest / hover / active6 / 6 + 1 outline / 8
  • Track, light / dark#DFDEDD / #393632
  • Fill, light / dark#171614 / #D0CEC8
  • Thumb fill, light / dark#FFFFFF / #211F1C
  • Thumb ring, light / dark#211F1C / #FFFFFF
  • Value bubble, light / dark#FFBA0D / #E3F200

Accessibility

The thumb is well handled in both themes. The track is not, and the value bubble is not in light mode.

Credit where it is due. The dark-mode block flips the thumb ring to #FFFFFF on a #211F1C fill, which is exactly right. Most of the other components in this pass did not get that treatment.
  • Build it on a real <input type="range"> where you can, and you inherit keyboard support for free.
  • A focus-visible ring is mandatory and does not exist yet. Ship one.
  • Arrow keys must move the value, and Home and End should reach the ends.
  • The accessible name must say what is being set, and the value needs a text form if the number is not plain — aria-valuetext for units.
  • The 24px thumb is below the 44px touch target guidance. Give it a larger invisible hit area.

Known gaps

  • The track fails contrast in both themes, and the two dark values disagree with Progress bar — #393632 here, #666054 there.
  • No focus-visible state. The most important missing piece.
  • No disabled state.
  • No keyboard behaviour — step, page step, Home and End are all undefined.
  • No tick marks, no min or max labels, no unit.
  • Range variant has no minimum gap and no collision rule.
  • The value bubble reuses tooltip/height and radius/sm but is not the Tooltip component.
  • The value bubble changes hue between themes, amber in light and yellow-green in dark. Confirmed deliberate.
  • 24px thumb is under the 44px touch target guidance with no larger hit area specified.
