Tabs

Peer views of the same object, switched in place. Tabs are wayfinding, not parameters: nothing is reconfigured, you are just looking somewhere else.

What changed in this version (October 2026). Rebuilt against Trinity Design System John V. The old page used the prototype’s blue (#3069E3) and yellow indicator with a 2px bar and a track line; the file has none of that. Tabs are ink-on-neutral: label #565147, selected #171614 with a 1px rule, hover with a #DFDEDD rule, focus a 2px ink border, disabled #7F796C. Padding is 12 / 8 (was 11 / 16). All values are tabs/tab-item/* tokens. Restructured to the Tooltip rulebook with Try it and Known gaps.

Anatomy

  • Tab itemBody/sm 14, padding 12px 8px (y / x), 34px tall. A <button role="tab">.
  • Indicator1px bottom border, #171614, on the selected tab only.
  • Hover line1px bottom border #DFDEDD on hover, so the pointer gets a cue before the label changes.
  • Focus2px border #171614, radius 4, drawn around the whole tab.
  • Count2 to 8 in the file (items=2 … 8). Past 8, the page needs rethinking, not a ninth tab.
  • GapNone; tabs sit edge to edge and the padding provides the spacing.
Tabs or segmented control? Tabs switch between views of one object — Overview, Sensors, History for a single truck. A Segmented control switches between representations of one dataset — All tickets, Fleet map, Phases. If the page title stays and the content below changes shape, you want the segmented control.

Behaviour

These are rules, not suggestions. Figma draws the item states and strips of 2 to 8. The rules below are the house rules. Build to this.
  • Instant and lossless. Switching never discards input. If moving away would lose unsaved work, tabs are the wrong component.
  • One selected on load. The first tab unless the URL says otherwise. Never open with nothing selected.
  • The tab lives in the URL. A view can be linked to and survives a refresh.
  • Past the width, scroll. The strip scrolls horizontally with no visible scrollbar; it never wraps and never becomes a dropdown. Keep the selected tab in view on load.
  • Keyboard. Tab lands on the selected tab; Left / Right move and select (automatic activation); Home / End jump. Tab again leaves the strip to the panel.
  • Labels. One or two words, no verbs. Order by how often they are used, most used first.

Guidelines

Do

  • Keep labels to one or two words.
  • Order them by use, most first.
  • Put the tab in the URL.
  • Use a Badge for a count, a dot for “changed”.
  • Keep the panel height stable between tabs where you can.

Do not

  • Use tabs for steps in a sequence; that is a stepper, and none exists yet.
  • Put one form across several tabs.
  • Wrap to a second row.
  • Use tabs and a segmented control for the same job on one screen.
  • Disable a tab without saying why.

Specs

  • Tab itempadding 12 / 8 · Body/sm 14 / 1.3 · height 34
  • Textdefault #565147 — 6.8:1 · hover / selected / focus #171614 — 15.6:1 (on #F0EEEA)
  • Rulesselected 1px #171614 · hover 1px #DFDEDD
  • Focus2px #171614, radius 4
  • Disabled#7F796C (exempt)
  • Count2 – 8
  • Dark (derived)default #B6B1A5 — 8.5:1 on #171614 · selected #FFFFFF · hover rule #45413A

Accessibility

  • Roles. role="tablist" with an aria-label; each tab role="tab" aria-selected aria-controls; each panel role="tabpanel" aria-labelledby.
  • Roving tabindex. Only the selected tab has tabindex="0"; arrows move focus and selection together.
  • Not colour alone. Selected has the rule and the darker label; two cues.
  • Hover rule #DFDEDD is 1.2:1 against the page: a pointer cue only, never the accessible one. Focus is the 2px ink border (3:1+).
  • Contrast. Default label 6.8:1, selected 15.6:1 light; 8.5:1 and 18:1 dark. All pass.

Known gaps

  • Light only in Figma. Dark values are derived.
  • No track line. The file draws no full-width rule under the strip; this page follows the file. If the Hub keeps the 1px track from the old version, it is a house addition.
  • Hover rule at 1.2:1 is below the 3:1 boundary and omitted from Specs as a pass; the label change carries hover.
  • No overflow affordance is drawn for 8+ tabs; the scroll rule is house.
