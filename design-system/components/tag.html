Verifi Design System/Components/Tag

Tag

A small label with an optional icon and an optional diagonal pattern. Its colours can be changed per use, within one rule: every pair is measured before it is used.

Solid6 combinationsLight and darkFigma 62678:46633 ↗
A tag is a label, not a control. It names a category or a quality of the thing it sits on. It cannot be clicked, selected or removed — that is a chip, which is a separate component. Its colour is meant to be changed per use, and this is one of the few components where that is allowed. The rule that makes it safe is the same one Badge uses: change only the fill and the text, measure the pair in both themes before you use it, and bring a colour that earns its place back to the library as a named token.

In Angular

For developers. Nothing in this section changes how the Tag looks or behaves. If you design in Figma or write the rules, you can skip it.

In the Angular code the Tag is one ready-made piece. Every colour, size and state on this page is already inside it, so the person building a screen chooses from the settings below and never restyles anything.

  • What you type<vf-tag>
  • What you can setlabel, icon, provisional (boolean: shows the diagonal and expects the label to say so), fill and text (colour tokens, only from an approved pair)
  • What it tells youNone. A tag is a label; anything clickable is a Chip.
  • What it handles for youA <span>. Truncates at 100px with an ellipsis and exposes the full label through the Tooltip on hover and on focus of the containing control. The icon is aria-hidden.

States

None. A tag is a label. If it needs to be clicked, selected or removed, it is a chip — a different component with its own states — not a tag with states added.

Behaviour

  • The icon and the diagonal are independent toggles, so all six combinations are legitimate.
  • The diagonal means provisional: an estimated, projected or not-yet-confirmed value. Because a pattern has no text equivalent, the label says so too — “Est. 14:20”, “Projected”. The pattern is never the only signal.
  • Only the 35% overlay is used. The solid form runs straight through the label and makes it hard to read, so it is not used on anything with text.
  • The label truncates at 100px with an ellipsis, and the full text shows in a Tooltip on hover and on keyboard focus. Nothing is lost, only shortened.
  • Fill and label colour can be changed per use. The default pair is the approved pair; any other pair is measured in both themes before it is used and proposed back to the library so the next screen gets it. Two people using the same meaning use the same colour.

Guidelines

Do

  • Measure any fill and label pair you choose, in both themes, before you use it.
  • Keep labels short enough to survive the 100px cap.
  • Write the word the diagonal stands for into the label.

Do not

  • Do not use a tag where a Truck phase tag belongs. Phases have nine defined colours and meanings; this does not.
  • Do not rely on the diagonal alone. It means provisional, and the label has to say so as well.
  • Do not make a tag look pressable. If it needs to be pressed, it is a chip.

Accessibility

The two default pairs pass. The light one passes by very little, which matters more than usual here because these colours are meant to be swapped by hand.

The examples are worse than the default. The documentation frame in Figma overrides the fill to #2778C1, which measures 4.62:1 — below the 4.83:1 of the #0975C3 default. Anyone who copies an example rather than starting from the component inherits the weaker pair. This page renders the default.
4.83:1 has no headroom. The light default clears 4.5:1 by a third of a point, and the stripe colours are overridable too, so a designer can change three things independently and break the pair without touching the one they were looking at. Measure the composite, not the fill.
  • Measure every fill and label pair you invent. The default pair is the only approved one until yours is added.
  • The stripe pattern changes the effective background under the text. Measure against the composited colour, not the base fill.
  • The icon is decorative unless it carries meaning the label does not. If it does, the icon needs a text equivalent.
  • A tag is never clickable, so it never takes focus. The tooltip on a truncated label opens on the focus of whatever the tag sits inside.

Known gaps

Solid, as a starting point. A tag is a label, the diagonal means provisional and always comes with a word, truncation has a tooltip, and any new colour follows the same measure-and-propose rule as Badge. Verifi is still discovering its full brand, so this can change — together, and always passing AA.

Figma housekeeping

Things the design file still has to catch up on. None of them change what is specified here.

  • Remove the letter-spacing: -2 binding at 12px. It is used nowhere else in the library and reads as a leftover.
  • Mark the solid diagonal as not for use, or remove it. Only the 35% overlay is used.
  • Tokenise the stripe pitch (3.7px on 7.1px) so the pattern renders the same everywhere; this page picked those values by measuring the file.
  • Bind the default fill and text to named tokens so “the approved pair” is something a file can point at.

Decided

  • Clickable and removable tags are chips. Chip is its own component in Figma and does not have a page here yet.
  • Truck phases never use a tag. They have their own component with nine fixed colours and meanings.
