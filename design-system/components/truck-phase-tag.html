Truck phase tag

The nine stages of a load, from waiting at the plant to ignition off. It is for truck phases and nothing else.

Solid9 phasesFigma 56361:2240 ↗
One token pair, three components. The phase pill, the map marker and the map legend dot all read from the same pair. A truck shown as Pouring in a list and On site on the map is a bug, not a design choice.

In Angular

For developers. Nothing in this section changes how the Truck phase tag looks or behaves. If you design in Figma or write the rules, you can skip it.

In the Angular code the Truck phase tag is one ready-made piece. Every colour, size and state on this page is already inside it, so the person building a screen chooses from the settings below and never restyles anything.

  • What you type<vf-phase-tag>
  • What you can setphase (one of the nine phase keys, in lifecycle order)
  • What it tells youNone. It reports nothing back; the page reads the native events.
  • What it handles for youA <span> whose text is the phase name, coloured from the phase token pair. No interactions, no role. Rejects any value outside the nine phases at compile time.

States

The phase tag has no interactive states. It is a label, not a control — it reports what the truck is doing and cannot be pressed, selected or dismissed.

If you need it to be pressable, you want a filter chip, and the phase colour does not come with it.

Behaviour

The colour roles invert. They do not tint. Light mode is the solid colour with white text. Dark mode is the light tint with near-black text. An early prototype rendered the same solid pill in both modes; that has been overruled.
  • This component is for the phase of a truck and nothing else. Every other status in the product — a unit’s state, an update’s progress, a flag, a count — is a Badge. The two never share a column.
  • The pill never reacts. Inside a clickable row, hover and focus belong to the row, and the pill stays exactly as it is. A pill that changed on hover would read as its own control, and it is not one.
  • The phase name is always written. Colour is the fast read, never the only read.
  • Phases are ordered by the lifecycle, not alphabetically, everywhere they are listed.
  • A truck has exactly one phase. There is no combined or transitional state.
  • The pill does not change size with the label. Long names such as “Waiting to load” simply make a wider pill.

Guidelines

Do

  • Always render the phase name alongside the colour.
  • Keep the lifecycle order in lists, legends and filters.
  • Use the same token for the pill, the marker and the legend dot.

Do not

  • Do not invent a tenth phase. Nine is the model.
  • Do not reuse phase colours for anything that is not a phase.
  • Do not bold or uppercase the label.
  • Do not use a phase colour as a background for a region or card.

Accessibility

Contrast for all eighteen combinations is measured on the Truck phases page. All eighteen pass.

Loaded is one shade darker than it was. The original #887F13 measured 4.12:1 with white text, the only one of eighteen that missed. #7A7211 measures 4.95:1 and keeps the same hue. The dark tint is unchanged.
  • The phase name is the accessible content. Never ship a bare coloured dot with no text.
  • The tag is not interactive, so it needs no role — but if it sits in a table cell, the cell is what gets announced.
  • Colour-blind users get no information from the hue. The label does all the real work, and that is by design.

Known gaps

Solid, as a starting point. Nine phases, nine colour pairs that all pass, one vocabulary, and a clear line between this and Badge. Verifi is still discovering its full brand, so this can change — together, and always passing AA.

Figma housekeeping

Things the design file still has to catch up on. None of them change what is specified here.

  • Change the Loaded light colour from #887F13 to #7A7211. One token, one value.
  • Two phases have two names. The words on screen win: To job and Return to plant. Rename the token Returning to plant and the variant In transit to match, so the component, the token and the screen all say the same thing.
  • An exact duplicate set exists at 57719:16219. 56361:2240 is canonical; retire the duplicate.

Decided

  • Truck phases only. Every other status is a Badge.
  • The pill never reacts. Inside a clickable row, the row carries hover and focus.
