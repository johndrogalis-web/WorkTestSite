Data colour

Six fixed colours, one per business area, used only for data. Light mode is the branded version; dark mode keeps each hue and lightens it. This is how charts are coloured. It is not the brand palette and it is not the UI palette.

V1 · for review6 areas3 shades eachLight and darkFigma 67641:557 ↗
What changed in this version (October 2026). New page, from the Trinity — Data Colors sheet (V1, for review). Everything here — the six area colours, the shade families, the hierarchy, the rules for metrics and markers — is taken from that sheet. The example charts are built from its values. The sheet is a proposal: this page may move or merge once it is reviewed, and says so in Known gaps.
Data only. These colours go on charts, the VPI bar, savings bars, area cards and legends. Never on buttons, navigation or status. For UI colour see Colour; for the brand see Colour and type.

In code

For developers. Nothing in this section changes how the data colour looks or behaves. If you design in Figma or write the rules, you can skip it.

The palette ships as CSS custom properties on the chart container, one set per theme, and every chart reads from them. No chart library carries its own colours.

Rules

These are rules, not suggestions. The Figma sheet (67641:557) sets the palette, the hierarchy and every rule below. Nothing here is a house addition. Build to this.

Always

  • One area, one colour, everywhere. Ops data is always this orange. Colour comes from the area, never from list position, sort or filter.
  • Light mode is the brand version. Dark mode keeps the same hue, only lighter.
  • Split touching marks with a 2px gap in the card colour. This is what makes neighbours pass AA in any order.
  • Always show the area name and value next to the colour, as a legend or a direct label.
  • Default VPI order: Quality, Materials, Contractor, Sustainability, Operations, Adoption.

Single-area charts

  • One area’s chart uses one hue: up to three shades, base colour first. Exactly one series gets the base, usually this period or this plant.
  • Light mode: extra shades go darker. Lighter tints fail 3:1 on white (Adoption excepted). Dark mode: one shade lighter, one darker; all pass on #2F2D28.
  • Comparisons reuse their series colour as a dash or a hatch. Last period, target, forecast: never a new shade.
  • More than three series: highlight one, grey the rest (#8A867F), or use small multiples.
  • Never borrow another area’s colour for a second series. A blue line in an Ops chart reads as Quality.
  • Ordered data (heatmaps, ranges) may use the full light-to-dark ramp, with the value shown in every cell.
  • Keep the darkest Operations shade away from Materials data; it drifts toward brown.

Metrics

Slump, water, drum speed, temperature and similar measurements are not categories, so they never get their own hue. A metric takes the colour of the area that owns the page. With no owner, it uses Ink.

  • Why. A hue per metric collides with the areas: green slump reads as Sustainability, orange admix as Operations, purple temperature as Adoption, brown drum speed as Materials, red revolutions as a problem. On a QC page every metric is Quality blue and the chart title names the metric.
  • Red appears only on a value that actually breaks a limit, with an icon or a word.
  • Never add a new palette. If a chart seems to need one, split it or use highlight + context.

Guidelines

Do

  • One area, one colour, everywhere.
  • Keep light mode as the brand version; dark mode is the same hue, lighter.
  • Put a 2px card-colour gap between touching marks.
  • Show the area name and value next to the colour.
  • Use the default VPI order.

Do not

  • Add a seventh hue. Past six series, or with no area meaning, use highlight + context or tints of one colour.
  • Give markers (you, goal, average, top 10%) a hue. Ink with a shape or dash.
  • Show status colours in the same chart as area colours.
  • Push Materials redder, or move Adoption toward a medium violet in light mode; both break separation.
  • Use Verifi Yellow #E3F200, or tooltip-only identification, for data.

Accessibility

  • Never colour alone. Every area is named next to its colour, in a legend or a direct label. Status always has an arrow or a word. Markers are shapes and dashes.
  • Fills 3:1, labels and text 4.5:1, on the card they sit on, in both modes. The 2px card-colour gap keeps touching marks separable whatever their order.
  • Colour blindness. Checked with simulation on the sheet. Closest pairs: Operations vs Sustainability (red-blind) and Quality vs Adoption in dark mode (green-blind). Labels stay required. The dataviz validator agrees and adds Materials vs Sustainability (protan) and Operations vs Contractor as the pairs to keep apart; see Known gaps.
  • A table view accompanies any chart the person has to act on. The chart is the summary; the table is the record.
  • Hover is not identification. Tooltips may add detail; they never carry the only name of a series.

Known gaps

V1, for review. The sheet is a proposal and so is this page. It may be folded into Colour or moved once the review lands; the rules are published now so new charts stop inventing palettes.
  • Negative status. The sheet notes #B44B6A is nearly Contractor magenta and proposes #D70100 light (the existing danger colour) / #FF8A80 dark. This page uses the proposal. Positive #457676 has no published dark value; derive before use.
  • Prototype markers. The goal marker is blue and the top-10% marker is orange today. Under tier 4 both become ink with a shape or dash.
  • Existing load-detail charts use a hue per metric (green slump, orange admix, purple temperature, brown drum speed, red revolutions) and a green discharge band. They move to the Metrics rule.
  • Separation, measured. Running the six light fills through the dataviz validator: adjacent-pair colour-blind separation is in the 6–8 floor band (Operations ↔ Sustainability ΔE 6.7 protan), legal only with the labels and gaps this page requires; across all pairs Materials ↔ Sustainability drops to 4.8 and Operations ↔ Contractor to 13 for normal vision, so never place those two beside each other without a label. Dark fills sit lighter than the validator’s categorical band; that is the sheet’s choice (ink labels on light fills) and passes contrast.
  • Not yet tested on real displays or with users.
