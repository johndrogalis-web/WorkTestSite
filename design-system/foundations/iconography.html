Verifi Design System/Foundations/Iconography

Iconography.

Two fonts, 1,431 glyphs. The name under an icon is not a label — it is the thing you type. Set a text layer to the font and type the name, or copy it into code.

Icons are a font here, not a folder of files. That is why the name matters more than the picture: TrinityIcons and TrinityBrandIcons resolve the name to a glyph, so changing an icon anywhere is a text edit, not an asset swap. Click any icon below to copy its name. Hover it and press SVG if you need the file instead.

The two fonts

FontHoldsUse it for
TrinityIcons1,415 interface icons — fi- from Feather, u- from UniconsEverything in the product. Navigation, actions, status, controls.
TrinityBrandIcons16 icons drawn for VerifiConcrete and fleet subjects nothing else covers — batching, slump, a ready-mix truck. Marketing and section headers, rarely inside a dense UI.
The two prefixes are two different drawings of the same idea. fi- icons are stroked on a 24px grid at 2px; u- icons are filled shapes. They do not mix well side by side, so pick one prefix for a screen and stay in it. Where both exist — fi-search and u-search — the Feather one is the default, because the product is drawn in strokes.

Sizes

Four, and they are the Icon component's own variants. The icon is always square and always sits on the same grid as the text beside it.

SizeBoxWhere
XSmall12pxInside a dense table row, or beside 12px text.
Small16pxThe default. Beside 14px body text, inside buttons and form controls.
Medium24pxStandalone actions, toolbar buttons, empty states.
Large32pxSection headers and feature callouts.
Never scale an icon to a size that is not on that list. A stroked icon drawn at 24 and displayed at 19 has a 1.6px stroke, which reads as blurry rather than lighter. If you need an in-between size, the answer is the next size down with more space around it.

Browse

Click any tile to copy its name. That name is what you type into a text layer set to the font — paste it straight into Figma and it folds to the glyph. Press SVG in the corner if you need the file instead.

Get the font

The brand set ships as a font. Install the .ttf and it appears in Figma’s font list; use the .woff2 on the web.

One name in the Figma legend does not match the font. The legend labels the sixth icon reporting; the font calls it data at U+E006. Only data folds to a glyph — typing reporting into a TrinityBrandIcons layer produces nothing at all. This page uses the font’s name and keeps reporting as a search alias, so searching either one finds the icon. The legend in Figma still needs correcting.
Only the brand font is here. TrinityIcons, the 1,415-icon set, is not published as a download yet. Its names are on this page and its SVGs are downloadable one at a time, but there is no .ttf to install. Anyone setting a Figma text layer to TrinityIcons needs the font from whoever built it.

Using them

In Figma

  • Use the Icon component rather than a text layer, so the size variants and the colour token come with it.
  • The component has an Icon property with two values: Default for TrinityIcons and Brand for TrinityBrandIcons. Switch the property rather than swapping the layer.
  • To change which glyph shows, edit the text inside the component and type the name. That is the whole mechanism.

In code

  • Bind the icon colour to the surrounding text colour. An icon that does not inherit currentColor will be wrong the first time it lands on a dark surface.
  • An icon that carries meaning on its own needs a name: aria-label on the control, not on the glyph.
  • An icon beside a text label is decoration — mark it aria-hidden="true" so the label is not read twice.
  • Icon fonts are read as text by some screen readers, which is how you end up with a private-use character announced as nothing at all. Always set aria-hidden or a label; never leave it to chance.

Accessibility

  • An icon-only button needs a 24 × 24 target, the same rule as the checkbox. The glyph can be 16 inside it.
  • Icons that carry state must not rely on shape alone at small sizes. At 12px a filled and an outlined circle are hard to tell apart — pair them with colour and text.
  • Non-text contrast applies: a meaningful icon needs 3:1 against its background, WCAG 1.4.11, AA. Decorative ones do not.
  • Never use an icon as the only way to convey something. It is the fastest thing to scan and the easiest thing to misread.
Where these come from. The fi- set is Feather (MIT) and the u- set is Unicons (line style). Both are packaged into TrinityIcons, so the names on this page are the names in the font. The 16 brand icons are original Verifi drawings and exist only in TrinityBrandIcons.
