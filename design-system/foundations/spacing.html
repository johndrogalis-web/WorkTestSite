Verifi Design System/Foundations/Spacing and layout

Spacing and layout.

Everything sits on a 4px grid. The application is a shell: a 244px navigation rail beside a Main Content region, and a fluid Page Grid that lives inside Main Content, never under the rail.

What changed in this version (October 2026). The frame numbers on this page came from the September Hub prototype (280px sidebar, 24px gutters, floating content card). The Figma page-layout spec (65601:82539) and the navigation spec replace them: a 244px rail inside an 8px shell, Main Content with a 16px inset, a fluid Page Grid with 12px gaps and 4 / 8 / 12 columns switching at 600 / 840 / 1200. The 4px scale and the page order below are unchanged. The full rules live on Page layout and Navigation; this page is the summary.

The 4px grid

Every dimension in the product is a multiple of four. Not because four is magic, but because one rule that is always true beats a hundred judgement calls.

StepUsed for
4pxIcon to its label, tight internal gaps
8pxBetween related controls, chip padding
10pxToolbar gap, between form options
12pxPage Grid column and row gap, card internal padding at small sizes
16pxCard and widget padding, Main Content inset (each side)
24pxSection spacing inside a page
32pxBetween major sections
48pxBetween page regions

The app frame

Two levels. The shell places navigation and Main Content. The Page Grid is calculated from Main Content alone: application width − persistent navigation = the width the grid divides.

  • Shellbg #F0EEEA · outer padding 8px · gap 8px between rail and content
  • Navigation rail244px wide, 8px padding; persistent at Large (≥ 1200) only. Below that a 72px top bar and the same menu as a drawer.
  • Main ContentWhat is left. bg #F6F4F2, 1px #DFDEDD border. Page header and controls sit at the top, full width.
  • Page GridInside Main Content: 16px inset each side, 12px column and row gap. Column width = (content width − 32 − (n−1)×12) / n.
  • ColumnsCompact (320–599) 4 · Medium (600–839) 8 · Expanded (840–1199) 12 · Large (≥ 1200) 12
  • Breakpoints600 · 840 · 1200. The only places the layout changes. Figma frame widths (360, 768, 1024, 1440) are examples, not breakpoints.
  • Rail itemsHeader 240 × 40, padding 12, 20px icon, 14/18 label, 6px active indicator · link item 244 × 34, padding 12 / 12 / 12 / 44
  • Rail footerUtility menu (Profile, Support, Settings) in the same landmark; the account block appears in the drawer on Mobile.
Session scope lives in the navigation. A separate Account / Division / Region / Plant scope bar appeared in early consultant screens and was cut. It will not be in the Verifi build.

Page order

Every Hub page stacks in the same order. Sticking to it is most of what makes the product feel like one product rather than twelve.

title row
↓ (stat band)
↓ toolbar
↓ (tabs)
↓ content
↓ (pagination)

  • Page title24px / 500, letter-spacing −0.72px
  • Subtitle12–13px in --soft
  • Right slotEither “Last updated: Today, 9:42 AM” or one page action as an outline pill. Not both.
  • Stat bandFull-width flex row, cells divided by 1px hairlines — not boxed cards. Label 16px above value 40px / 500. 3 to 6 stats.
  • Toolbar44px controls, 10px gap

The toolbar

Left to right, always in this order:

  • Pill search input, with a placeholder listing what is searchable — “Ticket, truck, order, mix, etc.”
  • Filters button with a funnel icon. Active state is a blue border, 6% blue background and a count badge.
  • One quiet primary action — “+ New ticket”, as an outline pill, not filled.
  • Columns menu (eye icon plus chevron).
  • Export, icon-only, 44 × 44.
  • Right-aligned: the segmented view switcher.

Table framing

Full-bleed

  • Full-bleed for a primary page table. No outer border, no clipping. The Main Content inset (16px) is the table edge.

Boxed

  • Boxed for a table inside a widget or card: 1px border, 8px radius, clipped.

The choice is contextual, not aesthetic. See Table.
