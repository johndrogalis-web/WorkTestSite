For designers.

Everything here comes from Trinity. The brand half governs what a customer sees outside the product; this half governs what happens inside it.

Six habits that make a screen look like Verifi

  • Use the quiet outline pill. Filled buttons are for completion, at most one per container. A screen full of solid buttons is not this product.
  • Let colour mean status, not decoration. Blue is selection. Red and amber are alerts. The nine phase colours belong to phases. Nothing else is coloured.
  • Keep the page order. Title, stat band, toolbar, tabs, content, pagination. Every page.
  • Open detail in a drawer, not a new page, so the list underneath survives.
  • Tint hover with the selection colour, never grey. 5% in both themes.
  • Put the horizon back in it. When a marketing layout is not working, a full-width image meeting a block of content on a clean line is almost always the answer.

What is safe to use today

StatusCountWhat it means for you

Has gaps0None today. When one appears it is written on the component page and counted on the index the same day.

Solid means solid today, not finished forever. Where a rule had to be set by Verifi Design rather than drawn in Figma (tooltip timing, the Secondary-only segmented control, the Pouring blue) the page says so in an Info note, so you can tell a drawn rule from a decided one.

What is not here yet

  • No stepper, no skeleton, no standalone empty state. The Dashboard page carries the Empty body pattern and the Table page carries its empty row; do not invent components to fill the other holes. Bring the case to Verifi Design.
  • Colour and Typography foundations still describe the product’s own token block. The component pages are the ones on Figma V2 tokens; where the two disagree, the component page wins until the foundations are refreshed.
  • One icon font, two sets — Feather (fi-) and Unicons (u-) inside TrinityIcons. Feather is the default where both have the icon. Keep one prefix per screen.
  • Specification frames in Figma may be set in Inter. Component text is ABC Repro; the spec text beside it does not have to be.

How it changes

This is a starting point, and a solid one, but Verifi is still small and still discovering its full brand. So it will change. Two rules hold while it does.

  • Together. A new colour, style or rule is proposed to Verifi Design and agreed before it ships. The person who needs it brings the case; the system carries the answer for everyone.
  • Still AA. Every colour pair is measured in both themes before it is added: 4.5:1 for text, 3:1 for an edge or an icon. Badge and Tag are built to take new colours this way; their pages say how.

Place the set the page names

Every component page lists its Figma node ID in the header. Place that set. The old duplicate clusters (side navigation, toast, table cells, truck phase tag, the broken top navigation) are no longer on any page of the file, so there is nothing to avoid; if a library search offers a set whose ID is not on the page, it is stale.
