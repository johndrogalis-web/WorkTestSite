Verifi Design System/Get started/For developers

For developers.

Every component page carries copy-and-paste HTML and CSS, scoped to the variant you are looking at. This page is the token set, the things that will bite you, and the numbers we measured rather than claimed.

The token set

The whole block, both themes, is on Foundations → Colour with a Copy button. Paste it into your root stylesheet and every snippet on this site works unchanged.

Ink tokens carry alpha on purpose. --defined is #36322D at 76%, not a solid grey, so text picks up whatever surface it sits on. That is also why contrast has to be composited before it is measured — the naive hex comparison gives the wrong answer.

Five things that will bite you

  • Lime is dark-mode only. --select is blue in light and lime in dark. If lime appears on a light screen, a token has been hardcoded somewhere.
  • Phase colours flip, they do not tint. Light is the solid colour with white text; dark is the light tint with near-black text. Same token pair, inverted roles. Pill, map marker and legend dot all read from it and must agree.
  • Hover is selection-tinted, never grey. 5% of the selection colour, both themes.
  • 46% of the button set’s fills are hardcoded in Figma. Generate CSS from the file rather than from the token block and you inherit values that will not follow a theme change.
  • The table component binds Montserrat and Font Awesome. Neither belongs to the rest of the system. Use ABC Repro and Unicons and flag it.

The two contrast failures

Measured, not asserted — the calculator runs in your browser on the accessibility page so you can check the arithmetic.

PairRatioVerdictFix
Phase pill Loaded #887F13 with white text4.12:1FailDarken to #7A7211 for 4.95:1. The only one of eighteen phase combinations that misses.
Light-mode --subtle on --layer-12.87:1FailBelow even the large-text bar, and it is the placeholder token. Use --soft at 14px or larger until it is darkened.

State naming, normalised

Three competing conventions coexist in the Figma file — state vs State, disabled vs isDisabled, value vs isSelected, intermediate vs isIndeterminate. Do not propagate that into code.

  • Statedefault · hover · focus · active
  • Booleansdisabled · selected · indeterminate · loading · inverse
  • Neverpressed (only the accordion has it), intermediate, isFoo

Motion, in four numbers

  • Colour and border0.14s
  • Popovers0.2s, fade plus a 4–6px rise
  • Drawers0.38s cubic-bezier(.22, 1, .36, 1)
  • Focus2px outline at 2px offset, never animated
