Components · Containers

Containers.

The things other things live in. Their corner radius is not decoration — it tells you what kind of object you are looking at.

Radius carries meaning

RadiusBelongs toWhy
4pxTags, small chips, banners Small enough that a pill would look like a mistake.
16pxCards, widgets, accordions, modals, drawers The default for anything holding content.
20pxLarge containers Rare. Use 16 unless something is genuinely oversized.
32px / 100pxButtons, inputs, segmented controls, phase pills Anything you press or type into is a pill.
Shadows mean floating. Cards, widgets and tables sit on the page and get a 1px border, never a shadow. Modals, drawers, popovers and toasts float above it and get one. If you are reaching for a shadow to make a panel stand out, you want a border and a different background instead.

Tables, because most of the product is one

Two treatments exist and the choice is contextual, not aesthetic.

Full-bleed

  • Primary page tables. No outer border, no clipping.
  • The page gutters are the table’s edges.

Boxed

  • Tables inside a widget or card: 1px border, 8px radius, clipped.
  • Keeps the table visually inside its container.
  • Header13px / 500, sticky, kebab menu per column on hover for hide and sort; drag to reorder; edge handle to resize
  • Cells13–14px --defined, 9–10px vertical padding, no wrapping
  • First columnseparated by a 1.5px rule
  • ZebraEven rows take --layer-2; 3% white in dark.
  • Hoverrgba(48,105,227,.05) light, rgba(227,242,0,.05) dark
  • Entity linksUnderlined, regular weight and family. Blue in light, white in dark. Never lime, never mono.
  • NumbersRight-aligned through the number cell type. Positive and negative deltas use the signed cell types, never ad-hoc colour.
  • Group headers#EBE7E0 band, 13px / 600, sticky, with a red count badge at 6px radius
  • Empty valuesAn em dash in --soft.
Thirty typed cells exist. Default, Number, Positive Number, Negative Number, Slot, Search, Active, Progress, Chart, User, User Group and DoubleSlot. If you are writing custom cell markup, check this list first — the cell you need has probably been drawn.

Widgets

Dashboard widgets are panels at 16px radius with a title row (16px / 600, icon buttons, and a “Go to X” pill link), a body, and a footer carrying “Last updated 1 minute ago” and pagination when the body is a table.

The widget grammar, in one line: every widget renders at all four sizes on the shared size scale. A thing that cannot survive being small is not a widget.

Known gaps

  • Modal has only one size. Extra small. The sm / md / lg widths in the CSS above are an interim proposal, not published values. There is also no header or footer slot spec and no close-affordance spec.
  • Card is a stub. The Figma page is called “Cards - missing” and holds one loose component with no variants. The card CSS above is taken from the widget pattern, which is the closest thing to a real spec.
  • The 30-variant cell set exists twice, and the table wrapper itself is a loose component with no variants. There is no sort spec, no selection spec and no empty state.
  • Two Hub components carry unnamed axes and a version number in the component name (Truck Card V.3).
