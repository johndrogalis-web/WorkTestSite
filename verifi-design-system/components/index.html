Components

All forty-five.

Everything the Trinity library actually contains, with an honest status on each one. Filter it, then follow a name through to the page that shows it working.

How we get to 45

The Figma file does not have a number on it, so here is the arithmetic. Thirty-seven core components across five families, plus eight Hub components that ship with the Diagnostic Center. Charts (17 sets) and Icons (1,416 components) are counted as libraries rather than components, because you pick from them rather than configure them.

Nine of the nine text-input types count as one entry. Text Input, Email, Phone, Password, Search, Date picker, Dropdown, Language selector and Text Area are nine loose Figma components that share a single private field underneath. Treating them as one family is how the design behaves, even if it is not how the file is organised.

What the statuses mean

StatusMeaningWhat to do
Solid Variants, states and rules are all present. Build against it.
Has gaps The component exists and works, but something is missing, duplicated or misnamed. The gap is written out in the row. Build against it, and read the gap before you rely on the part that is missing.
Broken Figma itself reports the set as structurally invalid. Do not build against it. Ask Verifi Design.
Missing No usable component. Tokens or a stub may exist. Use the written rule on the relevant page, and expect it to change.
