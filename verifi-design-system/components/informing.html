Telling people things.

Eleven ways to say something is happening, ranked by how much of the user’s attention they take. Take the least you can get away with.

The loudness ladder

Read this top to bottom and stop at the first row that is true. Almost everything belongs further down than it first appears.

The phase pills are the one component whose colours genuinely change between themes: solid colour with white text in light, a light tint with near-black text in dark.

Four severities, and only four

Message and Toast share one severity grammar: info, success, warning, error, coloured by the system/* tokens. Any new informer uses exactly these four. There is no fifth, no “critical”, no “notice”.

Alert badges are stricter still. Error is a solid red chip with a white icon and count. Warning is a solid amber #FFBA0D chip with a dark #36322D triangle and count — amber holds its contrast on dark, so it does not change. Never tint a warning red. Neutral statuses such as “Unlinked” use a grey chip and never borrow an alert colour.

Toast rules

  • Five seconds by default.
  • Error toasts persist until dismissed. An error that vanishes is an error nobody saw.
  • One stack region per viewport, newest on top, three visible at most.
  • If the user has to act on it, it is not a toast. Use an inline message or a modal.

Phase pills, markers and legend dots

The nine truck phases drive three things at once: the pill in a table, the marker on the map, and the dot in the map legend. They read from the same token, and they must always agree. A truck shown as Pouring in a list and On site on the map is a bug, not a design choice.

The nine phases, with contrast measured in both themes →

One phase fails contrast. Loaded at #887F13 with white text measures 4.12:1 — under the 4.5:1 bar, and the only one of the eighteen combinations that misses. The fix is one shade darker. The measurement is on the accessibility page.

The numbers

  • Tag20px high, 6px padding, 4px radius, 12px / 500
  • Badge20px high, 8px padding, 16px radius, 11px / 500
  • Phase pill12px / 400, 4px × 10px padding, 32px radius
  • Version pillmono 10px on --layer-2, 16px radius, no colour coding
  • Connection dot7px — green #16A34A live, 25% neutral when there is none
  • Spinner16 inline · 24 in a panel · 40 for a page
  • Avatar48 / 32 / 24 / 16, circle or squircle — pick one shape per product and never mix them in a view
  • Empty valuean em dash in --soft, never a blank cell

Known gaps

  • Banner has no severity axis, which makes it the odd one out. Until it does, use the four-severity grammar by hand.
  • Badge only drew three of its six size and content combinations.
  • Progress bar carries two junk variants and has no indeterminate state — use the spinner when you do not know the total.
  • There is no skeleton component. Do not build a fake one.
  • There is no empty-state component. The interim rule: say what would appear there, and offer exactly one action when the user can create it. Never a bare blank panel.
